# MultiCam Recorder

Windows PC に接続した複数の USB Web カメラを、同時にプレビュー・録画するデスクトップアプリです。

## 主な機能

- 接続された Web カメラを自動検出
- 複数カメラのライブプレビュー
- 共通の開始イベントによる複数台の一括録画
- 640×480 / 1280×720 / 1920×1080、15 / 24 / 30 / 60 FPS の指定
- カメラごとに MP4 ファイルを保存
- 録画日時・解像度・フレーム数を `session.json` に保存

## 必要なもの

- Windows 10 または Windows 11
- [uv](https://docs.astral.sh/uv/)
- 1台以上の Web カメラ

Python は `uv` が自動で用意できます。PCに別途 Python をインストールする必要はありません。

## 起動

PowerShell でこのフォルダーを開き、次を実行します。

```powershell
uv sync
uv run multicam-recorder
```

初回のみ Python と依存パッケージの準備に少し時間がかかります。

## 使い方

1. 使用するカメラにチェックを入れます。
2. 画質、FPS、保存先を指定します。
3. 「プレビュー開始」を押し、すべての映像が表示されるのを待ちます。
4. 「録画開始」を押します。
5. 「録画停止」を押すと、保存先に日時名のフォルダーが作られます。

保存例:

```text
recordings/
└── 20260927_123456/
    ├── camera_00.mp4
    ├── camera_01.mp4
    └── session.json
```

## Windows の設定

カメラが見つからない場合は、「設定 → プライバシーとセキュリティ → カメラ」で、デスクトップアプリのカメラ利用を許可してください。Zoom、Teams、ブラウザーなどがカメラを使用中の場合は終了してから再検出してください。

## 同期精度について

録画開始は全カメラで同じソフトウェアイベントを共有しますが、一般的な USB Web カメラには共通クロックや外部トリガーがないため、フレーム単位の厳密なハードウェア同期ではありません。厳密な同期が必要な計測用途では、外部トリガー対応カメラと専用 SDK が必要です。
